# A2 Unit 14 — Proslave (Celebrations & Food Culture)

## Overview

The seventh and final case — **VOCATIVE** — plus the **imperative**: the two tools for talking *to* people rather than *about* them. With all 7 cases now met, the unit turns social: birthdays, Božić, recipes, invitations and wishes. Dates with GEN (prvog siječnja) recycle Unit 13's genitive momentum, and the fixed wish-chunks (čestitam ti, želim ti…) quietly preview the DAT clitics that Unit 15 will make systematic.

## Can-do objectives

- I can address people directly and correctly (Ivane! bako! gospodine!)
- I can give instructions and commands, politely and plainly (Dođi! Nemojte čekati!)
- I can follow and give a simple recipe
- I can say and ask dates (Božić je dvadeset petog prosinca.)
- I can invite someone to a celebration and offer good wishes

## Lessons

### L1 — Ivane! Bako! (The vocative)

- **Grammar micro-point:** VOC — the "calling" case: masc consonant → **-e** (Ivan→Ivane, gospodin→gospodine), after palatals → **-u** (prijatelju), k/g/h mutate (momak→momče, Bog→Bože); fem -a → **-o** (ženo, bako, gospođo), -ica → **-ice** (gospođice, prijateljice); personal names in -a usually keep NOM (Ana!) though -o exists (Ano!); Marko, Tom and other -o/foreign names stay unchanged. → grammar-reference §3 (VOC rows)
- **New vocab:** L1 set
- **Required visuals:** **VOC endings table** (masc -e/-u/-če · fem -o/-ice · names column — endings in VOC pink) + usage-map diagram (when? calling, greeting, letters/emails, wishes → arrows to *Ivane!*, *Dobar dan, susjede!*, *Draga bako,…*); declension table gets its final row — "all 7 cases collected" celebration card
- **Slide arc:** Hook: "The last case of Croatian — and it's the friendliest one." → Teach: VOC table + pink endings → Examples + TTS: *Ivane, kava je tu!* (Ivan, the coffee's here!) · *Dobar dan, susjede!* (Good day, neighbour!) · *Bako, kako si?* (Grandma, how are you?) → MC ×3 (pick the VOC: gospodin → ?) → Teach: names behaviour (Ana!/Ano!, Marko unchanged) + letter openings (Draga Ana, / Dragi Ivane,) → type ×3 (call these people: momak → Momče!) → listen-type ×2 → match: NOM ↔ VOC pairs → fill ×2 (*Dobar dan, ___! (susjed)* → susjede · *Draga ___, (baka)* → bako) → speak: call two cast members aloud (*Bako, kako si?* · *Ivane, kava je tu!*) → interleave ×2 → Recap
- **Interleaving:** ti/Vi register (U1: gospodine + Vi), drago mi je (U1), gospodin/gospođa (U1)
- **SRS:** L1 vocab; cloze: "Ivan → ___!" (Ivane), "baka → ___!" (bako), "gospođa → ___!" (gospođo)

### L2 — Dođi na proslavu! (The imperative)

- **Grammar micro-point:** imperative formation: 2sg **-j / -i** (čitaj!, pjevaj!, otvori!, stavi!), 1pl **-jmo/-imo**, 2pl/Vi **-jte/-ite** (čitajte!, otvorite!); stem from present 3pl (pjevaju→pjevaj, otvore→otvori); irregular budi (biti), dođi (doći), jedi (jesti), pij (piti). → grammar-reference §10
- **New vocab:** L2 set
- **Required visuals:** **imperative formation table** (present 3pl → drop ending → -j/-jmo/-jte vs -i/-imo/-ite, endings bolded and coloured, per §4 conjugation row); irregular-four card (budi, dođi, jedi, pij); ti/Vi imperative twin card (Dođi! ↔ Dođite!)
- **Slide arc:** Hook: "Today you learn to boss people around — nicely." → Teach: formation table → Examples + TTS: *Dođi na proslavu!* (Come to the party!) · *Otvori poklon!* (Open the present!) · *Pjevajte s nama!* (Sing with us!) → MC ×3 (which form for Vi?) → Teach: irregulars + party vocab (glazba, pjesma, plesati) → type ×3 (tell a friend: bring the gift! → Donesi poklon!) → fill ×2 (dialogue: party prep) → reorder ×1: na / dođi / proslavu → listen-type ×2 (*Dođite na proslavu!* · *Otvori poklon!*) → speak ×1 (invite someone out loud) → interleave ×3 → Recap
- **Interleaving:** na + ACC direction (U5: *dođi na proslavu* ~ *idem na koncert*), s/sa + INS (U12: *pjevajte s nama*), modals (U11: *Moraš doći!* vs *Dođi!* — two ways to push)
- **SRS:** L2 vocab; cloze: "doći → ___!" (dođi), "otvoriti (Vi) → ___!" (otvorite); VOC+imperative combo cards (*Marko, donesi glazbu!*)

### L3 — Bakin recept (Negative imperative + recipes)

- **Grammar micro-point:** negative imperative = **nemoj / nemojmo / nemojte + infinitive** (Nemoj otvoriti!); recipes as the natural imperative habitat (dodaj, miješaj, stavi). → grammar-reference §10
- **New vocab:** L3 set
- **Required visuals:** nemoj + infinitive plug-diagram (nemoj as a socket, any infinitive plugs in); recipe step-card strip (numbered steps 1–5, each an imperative with icon: 🥚 dodaj jaja → 🥄 miješaj → 🔥 stavi u pećnicu); jaje→jaja plural warning card
- **Slide arc:** Hook: TTS reads baka Marija's cake recipe — "you'll follow every word." → Teach: nemoj + inf plug-diagram → Examples + TTS: *Dodaj šećer i brašno.* (Add the sugar and flour.) · *Miješaj pet minuta.* (Stir for five minutes.) · *Nemoj jesti tortu prije proslave!* (Don't eat the cake before the party!) → MC ×3 (nemoj + which form? infinitive, not imperative) → Teach: recipe vocab with step-card strip → fill ×3 (complete the recipe steps) → reorder ×1: nemoj / poklon / otvoriti → listen-type ×2 (dodaj tri jaja) → speak: read a recipe step aloud (*Dodaj šećer i miješaj!*) → interleave ×2 → Recap
- **Interleaving:** GEN quantities (U7/U13: *malo šećera*, *pet minuta*, *tristo grama brašna*), prije + GEN (U9 preposition set), food vocab (U4: kruh, mlijeko in recipe context)
- **SRS:** L3 vocab; cloze: "Nemoj ___ (jesti/jedi?)" → jesti; recipe-chunk cards; "tri ___ (jaje)" → jaja

### L4 — Kada je Božić? (Dates with GEN + months review)

- **Grammar micro-point:** dates take **GEN**: ordinal + month in GEN (prvog siječnja, dvadeset petog prosinca, trećeg svibnja); asking with Kada…? / Koji je datum?; GEN-of-time chunks (ove godine, sljedeće godine). → grammar-reference §13 (ordinals), §3 (GEN)
- **New vocab:** L4 set
- **Required visuals:** year-wheel diagram (12 months around a circle, blagdani pinned: Božić 25.12., Nova godina 1.1., Uskrs movable) with each pinned date written in GEN green; date-transformation card (25. prosinac → dvadeset pet**og** prosin**ca**, moving-morpheme highlight — note the fleeting a: prosinac→prosinca!)
- **Slide arc:** Hook: "When's your birthday? Answer like a Croatian — in the genitive." → Teach: date pattern + transformation card → Examples + TTS: *Božić je dvadeset petog prosinca.* (Christmas is on December 25th.) · *Moj rođendan je trećeg svibnja.* (My birthday is on May 3rd.) · *Kada je Uskrs ove godine?* (When is Easter this year?) → MC ×3 (match date ↔ spoken form) → Teach: blagdan vocab + year wheel → type ×2 (say your own birthday date) → fill ×2 → listen-type ×2 (TTS says a date, learner types digits) → speak: say your own birthday date (*Moj rođendan je trećeg svibnja.*) → interleave ×3 → Recap
- **Interleaving:** months (U6 — full review via year wheel), ordinals (U5: prvi→prvog), numbers (U7), perfekt (U8: *Prošle godine smo slavili kod bake.*)
- **SRS:** L4 vocab; cloze date cards ("25.12. → dvadeset petog ___" → prosinca); "moj rođendan je ___" personalized card

### L5 — Sretan rođendan! (Invitations & wishes, review)

- **Grammar micro-point:** the wish system: **čestitati + DAT** (Čestitam ti/Vam rođendan!) and želim ti + ACC of the wished thing (puno sreće i zdravlja — GEN after puno!); fixed wish formulas (Sretan rođendan! Sretan Božić! Sretna Nova godina! Živjeli!). ti/Vam here are taught as chunks — the full clitic system arrives in Unit 15.
- **New vocab:** L5 set
- **Required visuals:** wish-formula gallery (occasion icon → formula: 🎂 Sretan rođendan! · 🎄 Sretan Božić! · 🎆 Sretna Nova godina! · 🥂 Živjeli! — adjective endings gender-coloured); pozivnica anatomy diagram (a real invitation card labelled: VOC opening → date in GEN → imperative "Dođi!" → wish closing)
- **Slide arc:** Hook: a TTS pozivnica arrives — "decode it, then write your own." → Teach: wish formulas + gallery → Examples + TTS: *Čestitam ti rođendan!* (Happy birthday to you! / I congratulate you.) · *Želim ti puno sreće i zdravlja!* (I wish you lots of luck and health!) · *Sretna Nova godina!* (Happy New Year!) → MC ×2 (which wish for which occasion?) → Teach: pozivnica anatomy → fill: complete an invitation (VOC + date + imperative + wish) → reorder ×1 → type ×2 → listen-type ×2 (*Želim ti puno sreće i zdravlja!* · a TTS date from a pozivnica) → speak: congratulate baka Marija out loud (VOC + wish) → integration ×2 with cast → unit-review slide set (8 quiz slides sampling L1–L4) → Recap
- **Interleaving:** puno + GEN (U13: *puno sreće*), future I (U9: *Doći ću sigurno!*), sviđati se (U10: *Sviđa mi se poklon!*)
- **SRS:** L5 vocab; wish-formula cloze cards (Sretan ___! by occasion); "čestitam ___ (ti/te?)" → ti

## Story — «Iznenađenje za baku Mariju» (A surprise for Grandma Marija)

Baka Marija is turning seventy. Ana organizes a secret party: Marko bakes the cake from baka's own recipe, Tom writes the invitations and learns the hard way that dates go in the genitive. Everyone hides; baka walks in; vocatives and wishes fly. 150–300 words; imperatives drive the preparation dialogue, VOC and wish formulas crown the finale.
Cast: Tom, Ana, Marko, baka Marija. New glossed words (≤5): tajna (secret), ništa (nothing), svi (everyone), vikati/viču (to shout). *(Corrected 2026-07-23: balon & ukras are now L2 vocab; reći → govoriti — see vocab correction note.)*
Sample sentences: »Nemoj ništa govoriti baki!« govori Ana Tomu. · »Bako, sretan rođendan! Želimo ti puno sreće i zdravlja!« viču svi.
Comprehension: 5 MC questions (Koliko godina ima baka? Tko radi tortu? Što Tom piše? …).

## Unit test blueprint (16–18 items, pass ≥ 70%)

1. **Vocab (5):** match HR↔EN ×2 (party words, holidays), MC ×3 (recipe verbs, wishes)
2. **Grammar (6):** VOC fill ×2 (Ivan → ___!; gospođa → ___!), imperative fill ×2 (doći, ti-form; otvoriti, Vi-form), nemoj MC ×1 (nemoj + jesti/jedi), date fill ×1 (Božić je dvadeset petog ___)
3. **Listening (4):** listen-type ×2 (*Dođite na proslavu!*, a date), listen + MC meaning ×2
4. **Reading (3):** a short pozivnica + 3 MC comprehension (kada, gdje, što donijeti)
Example item: fill — »___ (Marko), donesi glazbu!« (Marko — unchanged!) · MC — "Sretan/Sretna/Sretno Nova godina!" → Sretna.

## NotesDoc focus per lesson

- **L1:** full VOC table incl. palatals and k/g/h mutation, all 7 cases now shown in one master table; mistakes: calling with NOM (*Ivan, dođi!* — heard colloquially but write Ivane!), *gospodine Horvate* vs common *gospodine Horvat* (surnames usually stay), Ana/Ano both fine — names in -a often keep NOM; hook: "pink is for people you're talking TO"
- **L2:** full formation table from present 3pl, all six imperative persons; mistakes: forming from the infinitive (*pjevatij* ❌), *dojdi* ❌ → dođi ✅, using infinitive as a command (English transfer); hook: "steal the stem from ONI"
- **L3:** nemoj paradigm complete; mistakes: *nemoj jedi* ❌ → nemoj jesti ✅ (infinitive after nemoj!), *nemoj da…* (regionalism — not standard here); note jaje→jaja irregular plural
- **L4:** all 12 months with their GEN forms in a table (siječnja, veljače, … prosinca — flag fleeting a in siječanj/travanj/lipanj/srpanj/prosinac); mistakes: *na prvi siječanj* ❌ → prvog siječnja ✅ (no preposition, just GEN!), English "on" transfer
- **L5:** wish-formula table with agreement (Sretan Božić m / Sretna Nova godina f / Sretno ljeto n); mistakes: *Sretan Nova godina* ❌ (agreement!), *čestitam te* ❌ → čestitam ti ✅ (DAT, not ACC); hook: čestitati is a "giving" verb — you give congratulations TO someone (U10 dative logic)
