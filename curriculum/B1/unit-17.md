# B1 Unit 17 — Mediji (Media & news basics) · Aspect mastery I

## Overview

The first B1 unit — and the payoff of U16's gentle aspect introduction: the learner stops memorizing pairs one by one and starts **seeing the machine that makes them**. Three formation patterns (prefixation, -nu-, stem change) plus the handful of suppletive pairs cover almost every verb they will ever meet; L4 then turns aspect from a form choice into a **storytelling skill** (imperfective background, perfective event spine — the shape of every news item and anecdote). The media theme supplies endless natural aspect contexts: you *read* the news every day (impf) but this morning you *read* one article to the end (pf). First B1 unit shape: 5 lessons + 300–500-word story + unit test + **guided writing task (80–150 words, AI rubric-graded, never gates)**.

## Can-do objectives

- I can look at a new verb pair and say which half is which, and how it was formed (prefix, -nu-, stem change, or suppletive)
- I can talk about media habits (impf) vs single completed media events (pf): Svaki dan čitam portale. Danas sam pročitao dug članak.
- I can understand and produce the suppletive pairs govoriti/reći, dolaziti/doći, odlaziti/otići in past, present and future
- I can narrate a small event in the past with an imperfective background and a perfective spine (Dok je Ana gledala vijesti, Marko je došao.)
- I can write 80–150 connected words about what I read/watched yesterday, choosing aspects correctly

## Lessons

### L1 — Novine i portali (Aspect pair formation I: prefixation)

- **Grammar micro-point:** most perfectives are just **prefix + the imperfective you already know**: na- (pisati→napisati, učiti→naučiti), pro- (čitati→pročitati), po- (gledati→pogledati, slušati→poslušati, piti→popiti). The prefix is lexical — you learn WHICH prefix per verb, but once you see the pattern, every new pair costs half the effort. Perfective present still ≠ now. → grammar-reference §11 "Pair-formation patterns" #1
- **New vocab:** L1 set (media nouns + poslušati)
- **Required visuals:** **aspect timeline diagram** (the U16 wavy-line/point visual — returns as the unit's flag) · **prefix-machine diagram** (flow: [impf verb] + [na-/pro-/po-] → [pf verb], each step with an example) · pair table with the prefix column highlighted
- **Slide arc:** menu → warm-up quiz-set (review: U16 pairs + U8 perfekt) → Hook: "In U16 you memorized six pairs. Today you get the machine that builds hundreds." → vocab-cards (media words) → Teach: prefix machine + table (pisati→napisati, čitati→pročitati, gledati→pogledati, slušati→poslušati, učiti→naučiti, piti→popiti) with timeline recall → Examples + TTS: *Svaki dan čitam novine.* (I read the paper every day.) · *Danas sam pročitao dug članak na portalu.* (Today I read a long article on the news site — to the end.) · *Novinar je napisao članak i naslov.* (The journalist wrote the article and the headline.) → quiz-set ×4 (which prefix? which half is pf?) → match (impf ↔ pf incl. poslušati) → fill ×3 (habit vs done context) → type ×2 → listen-type ×2 (*Danas sam pročitao dug članak.* · *Novinar piše članak.*) → speak (one habit + one completed media act) → interleave ×2 → Recap
- **Interleaving:** U16 L1 pair vocabulary (napisati, pročitati…), U8 perfekt agreement, U7 kupovati in a habit sentence
- **SRS:** L1 vocab; cloze "Svaki dan ___ (čitati/pročitati) portale." → čitam; pattern card "slušati → pf ___" → poslušati

### L2 — Na televiziji (Pair formation II: -nu- perfectives & stem changes)

- **Grammar micro-point:** two more machines: **-nuti perfectives** (dizati→dignuti — participle **digao/digla**, the -nu drops in standard past; krenuti from U9 belongs here: kretati→krenuti) and **stem-change pairs** where the imperfective carries a longer -ava/-iva/-inja stem (kupovati→kupiti, davati→dati, počinjati→početi, završavati→završiti). Reading trick: see a perfective, add -avati/-ivati → usually its imperfective. → grammar-reference §11 #2–3
- **New vocab:** L2 set (TV words + dizati/dignuti + dati)
- **Required visuals:** **pattern-sorter diagram** (three bins: PREFIX | -NU- | STEM CHANGE, each with its example pairs) · digao/digla warning callout (NOT dignuo in writing) · TV-studio vocab grid
- **Slide arc:** menu → warm-up quiz-set (L1 prefixes ×2 + U6 vijesti ×1) → Hook: "Yesterday's machine made pairs with prefixes. Croatian has two more machines — and you already own half their output." → vocab-cards → Teach: pattern sorter (bin 2: dizati→dignuti, kretati→krenuti; bin 3: kupovati→kupiti, davati→dati, počinjati→početi, završavati→završiti) → Examples + TTS: *Ana gleda vijesti na televiziji.* (Ana watches the news on TV.) · *Voditelj je počeo emisiju u osam.* (The host started the show at eight.) · *Baka mi je dala novine.* (Grandma gave me the newspaper.) · *Digla je ruku.* (She raised her hand.) → quiz-set ×4 (sort the pair into its bin) → mc ×2 (digao or dignuo? dala or davala?) → fill ×3 → type ×2 → listen-type ×2 (*Voditelj je počeo emisiju u osam.* · *Baka mi je dala novine.*) → reorder ×1 → speak → interleave ×2 → Recap
- **Interleaving:** U9 krenuti (now explained as kretati→krenuti), U15 DAT clitic (*Baka mi je dala…*), U6 time-of-day + u osam
- **SRS:** L2 vocab; cloze "Baka mi je ___ (dati) novine." → dala; pattern card "kupiti → impf ___" → kupovati; "digao/digla" form card

### L3 — Slušam radio (Suppletive pairs & aspect with habits)

- **Grammar micro-point:** a few pairs share no stem at all — **suppletives**, and they are the most common verbs in the language: govoriti→**reći** (rekao/rekla; everyday "I say" = kažem), dolaziti→**doći** (dođem, došao — you have written *doći ću* since Unit 9!), odlaziti→**otići** (odem, otišao), plus uzimati→**uzeti** (uzmem, uzeo — the U11 pill chunk). Second point: **habits are ALWAYS imperfective**, even when each act finishes (Svaki dan kupujem novine — each purchase completes, the habit doesn't). → grammar-reference §11 #4 + "habits" anchor
- **New vocab:** L3 set
- **Required visuals:** **suppletive-pairs table** (impf | pf | past forms — no visual similarity, so the table IS the memory object) · habit-vs-event contrast diagram (calendar with repeating wavy loops vs one flagged point) · "you've said this for months" payoff callout (doći ću U9, uzeti tabletu U11, javit ću se U12 — all suppletive/pf halves)
- **Slide arc:** menu → warm-up quiz-set (L2 bins ×2 + U11 uzeti chunk ×1) → Hook: "Some pairs weren't built by any machine — they're two different words. You already use four of them." → vocab-cards → Teach: suppletive table + payoff callout → Examples + TTS: *Ujutro slušam radio.* (In the morning I listen to the radio.) · *Tom dolazi svaki dan, ali danas je došao rano.* (Tom comes every day, but today he came early.) · *Baka je rekla: »Dolazim sutra!«* (Grandma said: "I'm coming tomorrow!") · *Uzeo sam novine i otišao.* (I took the paper and left.) → Teach 2: habit-vs-event (habits impf even when acts complete) → quiz-set ×4 → mc ×2 → fill ×3 (*Svaki dan ___ (dolaziti/doći) na posao. Danas ___ (dolaziti/doći) rano.*) → type ×2 → listen-type ×2 (*Uzeo sam novine i otišao.* · *Ujutro slušam radio.*) → speak → interleave ×2 → Recap
- **Interleaving:** U9 future spelling (doći ću vs pisat ću — now with the full pair), U6 frequency adverbs (uvijek/ponekad/obično) as impf magnets, U12 javiti se
- **SRS:** L3 vocab; cloze "Danas je Tom ___ (doći) rano." → došao; "govoriti → pf ___" → reći; "Svaki dan ___ (kupovati/kupiti) novine." → kupujem
- **Note:** odlaziti appears in the teach table as otići's partner but is NOT quizzed for production (recognition only — keep quiz answers to carded vocab).

### L4 — Vijest dana (Aspect in past narration — the story spine)

- **Grammar micro-point:** narration has a grammar: **imperfective = the background scenery** (what was going on), **perfective = the events that move the story** (what happened, one after another). **dok + imperfective** opens the frame; the perfective chain carries the plot; odjednom/napokon are perfective magnets. *Dok je Ana gledala vijesti, Marko je došao.* This is how every news item, anecdote and biography works. → grammar-reference §11 "narration spine" anchor
- **New vocab:** L4 set
- **Required visuals:** **story-spine diagram** (a horizontal wavy background band labeled "dok + impf" with 2–3 perfective event pins on top — the unit's flagship visual, the L4 evolution of the U16 life-timeline) · context-magnet table v2 (dok/cijeli dan/svaki dan → 〰️; odjednom/napokon/i onda → •✓) · news-item anatomy card (naslov → što se dogodilo (pf spine) → pozadina (impf))
- **Slide arc:** menu → warm-up quiz-set (L3 suppletives ×2 + U16 past-aspect ×1) → Hook: TTS plays a 4-sentence mini news item — "hear how the verbs take turns: background… event! background… event!" → vocab-cards → Teach: story-spine diagram + magnets → Examples + TTS: *Dok je Ana gledala vijesti, Marko je došao.* (While Ana was watching the news, Marko arrived.) · *Odjednom je počela kiša.* (Suddenly it started raining.) · *Što se dogodilo?* (What happened?) · *Portal je napokon objavio vijest.* (The news site finally published the story.) → quiz-set ×4 (background or event?) → mc ×2 → fill ×4 (complete a mini-news-item choosing aspect, taught words only: *Dok je voditelj govorio, gledatelji su slušali. Odjednom je ___ (počinjati/početi) kiša. Napokon je portal ___ (objavljivati/objaviti) vijest.*) → reorder ×1 (dok-sentence) → type ×2 → listen-type ×2 (*Dok je Ana gledala vijesti, Marko je došao.* · *Odjednom je počela kiša.*) → speak (narrate yesterday: one dok-background + one event) → interleave ×2 → Recap
- **Interleaving:** U15 clitic order in dok-clauses (*Dok je Ana gledala…* — je in 2nd position of its clause), U16 context magnets, U8 kiša/weather perfekt
- **SRS:** L4 vocab; cloze "___ je Ana gledala vijesti, Marko je došao. (while)" → Dok; "Odjednom je ___ (počinjati/početi) kiša." → počela; "Što se ___ (dogoditi)?" → dogodilo
- **Note:** objavljivati is taught with its -ujem present (objavljujem) — flag the -iva→-uje shift explicitly (same family as kupovati→kupujem from U7).

### L5 — Moji mediji (Consolidation + the first B1 writing task)

- **Grammar micro-point:** no new machinery — **aspect-choice fluency across past AND future**, mixed contexts, all four formation patterns interleaved; then the unit's exit performance: the guided writing task "Što sam jučer čitao i gledao" (80–150 words), rehearsed on-slide before the test carries it. → grammar-reference §11 (whole section)
- **New vocab:** L5 set (small by design)
- **Required visuals:** **pattern-sorter grand table** (all four bins with every pair met in U16–U17 — the unit's printable) · my-media-day planner (ujutro 📻 → popodne 📰 → navečer 📺, each slot with an impf habit + a pf achievement frame) · writing-task scaffold card (opening line → 2 habits (impf) → 2 things finished yesterday (pf) → one dok-sentence → closing plan (future))
- **Slide arc:** menu → warm-up quiz-set (L4 spine ×2 + U13 comparative ×1) → Hook: "Four patterns, forty verbs, one skill: you now choose aspect like a native chooses tone of voice." → vocab-cards → Teach: grand table + media-day planner → Examples + TTS: *Novinar je napravio intervju s Markom.* (The journalist did an interview with Marko.) · *Reklama je bila duga.* (The ad was long.) · *Navečer ću pogledati jednu emisiju.* (Tonight I'll watch one show — to the end.) → quiz-set ×4 (mixed pattern ID + aspect choice) → fill ×4 (past + future mixed) → type ×3 (own media habits/events) → reorder ×1 → listen-type ×2 (*Novinar je napravio intervju s Markom.* · *Navečer ću pogledati jednu emisiju.*) → speak (my media day in 4+ sentences) → integration ×2 (Tom's media day — cast) → unit-review quiz-set (6 items sampling L1–L4) → **writing-rehearsal slide** (teach: the scaffold card + a 90-word model text with aspect choices color-marked) → Recap + pointer to the test's writing task
- **Interleaving:** U12 s + INS (intervju s Markom), U13 adjectives (dug/duga), U9 future I + L1–L4 pairs in future
- **SRS:** L5 vocab; cloze "Novinar je napravio intervju ___ Markom." → s; personalized "Jučer sam pročitao/pročitala ___" card
- **Note:** the model writing text must stay inside taught grammar (no o + LOC "about" — express topics with direct objects: *čitao sam članak, gledala sam emisiju*).

## Story — «Vijest dana» (The news item of the day)

**~320 words (B1 length: 300–500), first story at B1 density.** A small news event told three ways — as it happens and as the media tell it. While baka Marija is listening to the radio and Ana is watching the evening news (imperfective background), a storm knocks a big old tree onto the market square in Split — right next to Marko's konoba (perfective spine: počela je kiša → vjetar je dignuo stolice → drvo je palo). Nobody is hurt; Marko calls Ana (javio se — the U12 chunk, live), a portal publishes the story with a dramatic headline, the TV carries it in the evening show, and Tom — reading the portal in Canada — recognizes Marko's konoba in the photo and messages him. Baka's dry commentary closes it: the radio said it first, kao i uvijek. The dok-construction appears ≥3 times; every event verb is a taught perfective; media vocab from L1–L4 all recurs.
Cast: Ana, Marko, baka Marija, Tom. New glossed words (≤5): oluja (storm), vjetar (wind), drvo (tree), pasti (palo — to fall), fotografija (photo).
Sample sentences: *Dok je baka slušala radio, vani je počela oluja.* · *Vjetar je dignuo stolice ispred konobe, a onda je palo veliko drvo.* · *Portal je odmah objavio vijest, a televizija ju je prenijela navečer.* — CORRECTION: avoid the ju-before-je clitic subtlety (untaught): *…a televizija je vijest prenijela navečer.*
Comprehension: 5 MC questions (Što je Ana radila kad je počela oluja? Što je vjetar dignuo? Tko je prvi objavio vijest? Kako je Tom vidio vijest? …), each answerable only by understanding the aspect/timeline.

## Unit test blueprint (18–20 items + writing, pass ≥ 70% on quiz sections)

1. **Vocab (5):** match media words ×1 (4 pairs), MC ×2 (voditelj/gledatelj/slušatelj -telj family; časopis vs novine), pair-completion fill ×2 (slušati → pf ___; kupiti → impf ___)
2. **Grammar (8):** pattern-sort MC ×2 (which machine built this pair?), aspect-in-past MC ×2 (*Dok je Ana ___ vijesti…* gledala/pogledala), aspect-in-future MC ×1, fill ×2 (*Danas je Tom ___ (doći) rano.*; *Odjednom je ___ (početi) kiša.*), suppletive type ×1 (past of "she said" → rekla je)
3. **Listening (4):** listen-type ×2 (*Dok je Ana gledala vijesti, Marko je došao.* — the spine sentence; *Uzeo sam novine i otišao.*), listen + MC ×2 (hear a sentence → "background or event?" / "finished or ongoing?")
4. **Reading (3):** a 6-line mini news item (taught vocab only) + 3 MC comprehension hinging on aspect (what was going on vs what happened)
5. **Writing task (attached to the test, AI-graded, never gates):** see below.
Example item: MC — *Svaki dan ___ novine.* (kupujem / kupim) → kupujem (habit = impf) · listen + MC — TTS: *Pisala je članak.* "Is the article finished?" → we don't know / not said to be finished.

## Writing task (B1 unit shape — first ever)

- **Title:** Što sam jučer čitao i gledao (What I read and watched yesterday)
- **Task (EN):** Write 80–150 words in Croatian about your media day yesterday: what you usually read/listen to/watch (imperfective habits), two things you actually finished yesterday (perfective: pročitao/la sam…, pogledao/la sam…), one dok-sentence (something happened while you were doing something), and one plan for tonight (future I, correct aspect). Use the L5 scaffold.
- **Word range:** 80–150 (counter shown)
- **Model text (HR, ~95 words, revealable):** authored in the content file — every verb aspect-correct, only taught vocabulary, dok-sentence included
- **Rubric focus:** aspect choice (habit vs completed vs narration), perfekt agreement, word order with clitics; task completion (all four required elements present)
