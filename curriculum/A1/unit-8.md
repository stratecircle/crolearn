# A1 Unit 8 — Jučer i danas (Weekend, Weather & the Past)

## Overview

The A1 finale: the **perfekt** opens the past tense, which instantly doubles what the learner can talk about. It's built from two things they already own — `biti` clitics (U1) and adjective-like agreement (U2/U3) — so it's taught as assembly, not novelty. The clitic second-position rule gets its full workout with `je`, including the famous `zvao se` (je-drop). Weather vocab gives natural past-narration material. Ends with the unit test and hands off to the A1 Checkpoint Exam.

## Can-do objectives

- I can say what I did yesterday and last weekend
- I can ask someone what they did (Što si radio/radila?)
- I can describe today's and yesterday's weather
- I can place the past-tense clitic correctly, including with reflexive verbs
- I can narrate a simple sequence of past events

## Lessons

### L1 — Bio sam u gradu (Perfekt of biti + the l-participle)

- **Grammar micro-point:** perfekt = **biti-clitic + l-participle**; participle of biti: bio/bila/bilo/bili/bile/bila — agrees like an adjective (U3 skill!). Gdje si bio? Bio sam u gradu. → grammar-reference §8
- **Required visuals:** perfekt assembly diagram (LEGO-style: [sam] + [bio/bila] = I was) with the two pieces colored; participle agreement table mirroring the U3 adjective table ("you already know these endings")
- **Slide arc:** Hook: "Everything you can say about today, you're about to say about yesterday." → Teach: assembly diagram + bio/bila table → Examples + TTS: Jučer sam bio kod kuće. Ana je bila u školi. Bili smo na koncertu. → MC ×3 (pick participle: Ana je ___ — bio/bila) → fill ×3 → type ×2: "I was at home", "We were at a party" → reorder: sam / jučer / u gradu / bio → listen-type ×2 (*Ana je bila u školi.* · *Bili smo na koncertu.*) → interleave ×2 (U5 LOC places — past now!) → speak: Jučer sam bio/bila kod kuće. (both gender forms shown, learner picks) → Recap
- **Interleaving:** U5 locations, U6 days (U ponedjeljak sam bio…)
- **SRS:** participle-agreement cloze cards; vocab
- **Watch-out (NotesDoc):** participle gender matches the SPEAKER for "ja" (Bio sam / Bila sam); ~~Sam bio~~ ❌ (clitic first — the U1 rule, again)

### L2 — Što si radio? (Perfekt of ordinary verbs)

- **Grammar micro-point:** l-participle formation from the infinitive: -ti → -o/-la/-lo… (radити→radio/radila; gledati→gledao/gledala; irregular: ići→išao/išla). Questions: Što si radio/radila? Jesi li gledala film? → grammar-reference §8
- **Required visuals:** participle factory diagram (infinitive in → chop -ti → add -o/-la/-li); irregular reds-list card (išao, jeo, htio — the only A1 irregulars); question-formation card (Jesi li + participle)
- **Slide arc:** Hook: TTS dialogue: »Što si radio jučer?« — »Igrao sam nogomet!« → Teach: factory diagram → Examples + TTS: Gledala je film. Putovali smo u Split. Išao sam u školu. → MC ×3 → fill ×4 (subject + infinitive prompt → perfekt) → type ×2: "Ana read a book", "We played football" → listen-type ×2 → interleave ×3 (U6 routine verbs in past: Tuširao sam se — preview of L3's se!) → speak: Jučer sam gledao/gledala film. → Recap
- **Interleaving:** U6 routine verbs, U4 jesti/piti (jeo, pio!)
- **SRS:** participle cloze per verb class; irregular trio cards
- **Watch-out:** išao/išla (NOT ~~ićao~~); pisati→pisao (regular — don't drag the present-tense š in: ~~pišao~~ ❌); agreement in WE-forms (bili smo m/mixed, bile smo f-only)

### L3 — Zvao se Marko (Clitic je and the second position)

- **Grammar micro-point:** the clitic cluster, descriptively: (1) clitics sit in **second position**, (2) **je goes after se** — no wait: **se + je → je DROPS** (Zvao se Marko, Tuširala se), (3) sam/si + se: order is aux → se (Budio sam se kasno). Question forms: Je li padala kiša? → grammar-reference §12
- **Required visuals:** the mandated **train-carriage diagram**, A1 edition: [first word] + wagons [sam/si/je] → [se], with the je-wagon shown uncoupling when se boards; ⚠️ big card: "3rd person + se: je disappears"
- **Slide arc:** Hook: »Kako se zvao? Zvao se Marko.« — "why no je? Today's mystery." → Teach: train diagram + je-drop rule → Examples + TTS: Budio sam se rano. Ana se tuširala. Zvao se Ivan. Je li bilo sunčano? → MC ×4 (correct/incorrect sentence judgment: ~~Zvao se je Marko~~ ❌) → reorder ×3 (heavy: se / je / building drills) → fill ×2 → listen-type ×2: *Ana se budila kasno.* · *Zvao se Ivan.* → speak: say when you woke up today (*Budio/Budila sam se u sedam.*) → interleave ×2 → Recap
- **Interleaving:** U6 reflexives (now in past); U1 Kako se zoveš? → Kako se zvao? payoff; L1–L2 perfekt
- **SRS:** word-order judgment cards; se+je cloze
- **Watch-out:** THE unit trap: ~~se je~~ ❌; second position means after the first PHRASE (Moja sestra se budila…) — taught by pattern, not theory

### L4 — Kakvo je vrijeme? (Weather, today & yesterday)

- **Grammar micro-point:** weather frames, present + past: Sunčano je. / Bilo je sunčano. · Pada kiša. / Padala je kiša. (neuter participle for weather!). Kakvo je vrijeme? → grammar-reference §8
- **Required visuals:** weather icon grid (☀️ sunčano, ☁️ oblačno, 🌧️ pada kiša, ❄️ pada snijeg, 💨 vjetar) with present/past toggle showing the frame change; today/yesterday split-screen diagram
- **Slide arc:** Hook: Zagreb vs Split live-weather guessing game via TTS → Teach: weather frames present → match: icon ↔ phrase → Teach: past frames (Bilo je hladno. Padala je kiša — kiša is fem, padala agrees!) → MC ×3 → fill ×3 (split-screen prompts: danas/jučer) → type ×2: "It's cold today", "It was sunny yesterday" → listen-type ×2 → interleave ×2 (U6 days: U subotu je padala kiša) → speak: Danas je sunčano i toplo. → Recap
- **Interleaving:** U6 days/times; U5 LOC (*U Splitu je bilo sunčano.*); L1–L3 perfekt machinery
- **SRS:** weather vocab + frame cloze (present↔past transforms)
- **Watch-out:** vrijeme = weather AND time (context card); Bilo je toplo (neuter, no subject); padala je kiša agreement

### L5 — Moj vikend (My weekend — A1 capstone)

- **Grammar micro-point:** none new — past-tense narration with sequencers (prvo, zatim, onda, na kraju — recycled U6) across the whole A1 toolkit: perfekt + LOC places + ACC objects + GEN quantities + times + weather.
- **Required visuals:** weekend-timeline template (Saturday/Sunday slots, learner fills their own); A1 achievement map — the full case table (NOM/ACC/GEN/LOC columns filled, DAT/INS/VOC greyed "coming in A2") + spine badges earned
- **Slide arc:** Hook: Ana's weekend monologue via TTS (8 sentences) → Examples + TTS: *U subotu sam gledala film.* · *Onda smo šetali i pili kavu.* → fill: her story with blanks → reorder ×2 → integration: build YOUR weekend (guided 8-slide chain: where, with what weather, what you ate/drank/watched — each slide one sentence, each recycling a different unit) → listen-type ×2 → speak ×2: two sentences of your weekend → unit-review set: 10 quiz slides sampling L1–L4 + U5–U7 spot checks → Recap: "A1 grammar complete — checkpoint exam unlocked" + achievement map
- **Interleaving:** everything (this lesson IS interleaving)
- **SRS:** learner's own weekend sentences as custom cards; sequencers refreshed
- **Watch-out:** none new — the notes for this lesson are the A1 exam study sheet (see below)

## Story — «Vikend u Splitu» (A weekend in Split)

Tom and Ana visit Marko in Split — told entirely in the past. Train trip (Putovali smo tri sata), sunny Saturday (Bilo je sunčano i vruće), seaside walk, Marko cooked fish, Sunday rain and a museum, tired-but-happy return. 130–150 words, perfekt throughout, weather woven in.
Cast: Tom, Ana, Marko. Glossed (≤5): more (sea), plaža (beach), povratak (return), umorni ali sretni (tired but happy, chunk). riba is recycled from U4 — no gloss.

*Authoring deviation (2026-07-22): `more` dropped from the glossary — it was taught in U2, so it is recycled, not new. Shipped glossary = plaža, povratak, umorni ali sretni (3). The evaluative masculine adjective forms `krasan`/`dosadan` (from the taught adverbs krasno/dosadno) appear once each as i+1 graded-reader inflections.*
Sample sentences: »U subotu je bilo sunčano i vruće.« · »Marko je kuhao ribu, a navečer smo šetali uz more.«
Comprehension: 4 MC (Kako su putovali? Kakvo je vrijeme bilo u nedjelju? Što je Marko kuhao? …)
