# A1 Checkpoint Exam — Ispit razine A1

Taken after Unit 8's unit test. Unlocks A2 (Unit 9). Per teaching-method §8: soft gate — a fail warns and recommends remediation but allows retake any time (≥2 days later recommended). ~45 minutes, may be paused between sections.

## Format overview

| Section | Items | Points | Skills |
|---|---|---|---|
| 1. Slušanje (Listening) | 10 | 15 | TTS comprehension + dictation |
| 2. Čitanje (Reading) | 8 | 12 | story-level passage + dialogue |
| 3. Gramatika i vokabular (Cloze) | 20 | 20 | all A1 grammar + vocab |
| 4. Govor (Speaking, AI-graded) | 5 prompts | 25 | pronunciation + production |
| **Total** | **43** | **72** | **pass ≥ 51 (70%)** |

No hints, no retry queue, first-attempt scoring. TTS replay allowed ×2 per listening item (slow mode allowed on dictation only).

## Section 1 — Slušanje (10 items, 15 pts)

- **Dictation (4 × 2 pts):** TTS sentence → learner types it. Pool constraint: ≤10 words, A1 vocab only, at least one diacritic word and one clitic. Examples: *Jučer je padala kiša.* · *Budim se u pola osam.*
- **Number/price/time catch (3 × 1 pt):** TTS says a time/price → learner types digits. Examples: *pola devet* → 8:30 · *šezdeset sedam eura* → 67
- **Dialogue comprehension (3 × ~1.3 pts):** 4–6 line TTS dialogue (café/shop/directions) → MC question each. Distractors must be plausible (same domain, wrong detail).

## Section 2 — Čitanje (8 items, 12 pts)

- **Passage (5 MC):** a fresh 120–150-word past-tense narrative using only A1 vocab (story-world cast, e.g. baka Marija's weekend). Questions target understanding, not word-matching (Zašto…? Kada…? question types included).
- **Dialogue gap (3 items):** printed dialogue with 3 missing turns → MC pick the pragmatically right line (tests courtesy system + question/answer pairing).

## Section 3 — Gramatika i vokabular (20 items, 20 pts)

Weighted to the A1 spine; every unit represented:

| Focus | Items | Example |
|---|---|---|
| biti + negation + questions (U1–U2) | 2 | ___ li ti student? → Jesi |
| Gender + adjective agreement (U2–U3) | 2 | To je ___ (crn) mačka. → crna |
| NOM/ACC pl (U3, U6) | 2 | Volim ___ (film, pl). → filmove |
| ACC sg incl. animate (U4) | 2 | Vidim ___ (brat). → brata |
| Present classes (U4) | 2 | Oni ___ (piti). → piju |
| LOC vs ACC direction (U5) | 2 | Idem ___ (grad). / Živim ___ (grad). → u grad / u gradu |
| Reflexives + time (U6) | 2 | Ana ___ budi rano. → se |
| GEN: quantity, nema, brackets (U7) | 3 | Nema ___ (kruh). → kruha · dva ___ (pivo) → piva |
| Perfekt + clitic order (U8) | 3 | Jučer ___ (ja, m, gledati) film. → sam gledao; judgment: ~~Zvala se je Ana~~ ❌ |

Item types: fill (typed, diacritic-tolerant grading per method §2), MC, reorder, judgment. Vocab coverage rides inside the grammar items (no separate word-list section).

## Section 4 — Govor (5 prompts, 25 pts, AI-graded)

Recorded via STT (transcript shown); the AI grader receives the transcript + task + rubric and returns structured scores with one-line feedback per criterion. Self-record retry allowed once per prompt (best attempt kept).

Prompts:
1. **Introduce yourself** (name, origin, profession/student, one thing you like) — 4+ sentences
2. **Describe the picture** (a café scene: who, what they're drinking/eating, one price)
3. **Answer the question:** *Što si radio/radila jučer?* — 3+ past-tense sentences
4. **Roleplay turn:** the app plays a shopkeeper line (*Izvolite! Što tražite?*) — respond appropriately, ask a price
5. **Read aloud:** a 20-word A1 paragraph (pronunciation-focused; STT transcript distance scored)

Rubric per prompt (1–5 each, summed and scaled to 5 pts/prompt):
- **Task completion** — did they do what was asked, with enough content?
- **Intelligibility/pronunciation** — would a patient native speaker follow? (diacritic-sound accuracy via STT distance)
- **Grammar accuracy** — A1-spine errors weighted (case endings, clitic position, agreement); errors above A1 level are NOT penalized

## Scoring, results & remediation

- Results screen: total + per-section bars + per-spine-item coverage map colored by performance ("weakest: GEN quantities").
- Every wrong item → priority SRS card (per method §8); weak spine areas → queued into "Practice more" AI exercise generation.
- **Pass (≥70%):** celebration card — »Čestitamo! Govorite hrvatski na razini A1.« — A2 (Unit 9) unlocks.
- **Fail:** warm no-shame screen; recommends the L5 review lessons of the 2 weakest units + the U8 L5 study-sheet note; retake button (suggest ≥2 days). Proceeding to A2 anyway is allowed (soft gate) after an explicit "I understand" confirm.

## Authoring constraints

- Exam items are FRESH (never copied from lessons/unit tests), drawn only from A1 vocab/grammar; validated by the same Zod schema as quiz slides; proofread pass mandatory (method §10).
- Balance both speaker genders in prompts and expected answers (radio/radila always both shown).
- Time estimate on the intro screen; sections completable in any order; progress saved between sections.
