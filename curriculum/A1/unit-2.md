# A1 Unit 2 — Ja sam iz… (Origins & Professions)

## Overview

First grammar-proper unit: noun gender is the master key that every later case table hangs on, so it comes first and gets a full lesson. Negation and yes/no questions complete the `biti` system started in U1; adjective agreement (NOM sg) cashes in the gender lesson immediately. Origins use **iz + country as memorized chunks** ("Ja sam iz Kanade") — flagged everywhere as *chunk, not yet analyzed* (GEN arrives in Unit 7). Numbers 1–20 are counting only (noun government waits for Unit 7).

## Can-do objectives

- I can say where I'm from and ask where someone is from (Odakle si? Ja sam iz…)
- I can say my nationality and profession, and negate them (Nisam Hrvat, Kanađanin sam)
- I can ask and answer yes/no questions (Jesi li student? — Jesam. / Nisam.)
- I can describe things with correctly agreeing adjectives (dobar čaj, dobra kava, dobro jutro)
- I can count 1–20 and say which languages I speak

## New vocabulary (~40 items)

**L1 (gender exemplars):** zemlja (f, country) · grad (m, city) · selo (n, village) · more (n, sea) · jezik (m, language) · Kanada (f) · Njemačka (f) · Engleska (f) · Amerika (f) · Francuska (f) · iz (from — chunk-tagged) · ili (or — bonus word here so L2 stays within the §2 12-item cap)

**L2 (nationalities):** Hrvat (m) / Hrvatica (f) · Kanađanin (m) / Kanađanka (f) · Nijemac (m) / Njemica (f) · Englez (m) / Engleskinja (f) · Amerikanac (m) / Amerikanka (f) · ali (but) · odakle (from where)

**L3 (professions + adjectives):** učitelj (m) / učiteljica (f) · liječnik (m) / liječnica (f) · konobar (m) / konobarica (f) · inženjer (m) / inženjerka (f) · dobar (good) · loš (bad) · nov (new) — kuhar/kuharica are TAUGHT in L3's profession grid but carded under L5 (keeps L3 within the §2 12-item cap)

**L4 (numbers):** jedan · dva · tri · četiri · pet · šest · sedam · osam · devet · deset · jedanaest · dvanaest · trinaest · četrnaest · petnaest · šesnaest · sedamnaest · osamnaest · devetnaest · dvadeset · koliko (how much/many) · broj (m, number)

**L5 (languages):** hrvatski · engleski · njemački · francuski · govoriti (govorim, to speak) · razumjeti (razumijem, to understand — teach as razumijem/ne razumijem chunk) · malo (a little) · jako (very) · kuhar (m) / kuharica (f) (introduced in L3; carded here)

## Lessons

### L1 — Rod imenica (Noun gender: -∅ / -a / -o,-e)

- **Grammar micro-point:** every noun is m/f/n; ending predicts it: consonant → m, -a → f, -o/-e → n; traps (tata m, noć/večer f, ime n). → grammar-reference §2
- **New vocab:** L1 set
- **Required visuals:** three-column gender sorting grid, gender-colored (m `sky-700`, f `rose-700`, n `amber-700`, gender letter always shown); trap-nouns warning card (tata, večer, noć, ime); country cards with flags
- **Slide arc:** Hook: "Every Croatian noun has a gender — and the word itself tells you which. Learn this once, use it for 7 cases." → Teach: the -∅/-a/-o,-e rule + sorting grid → Examples + TTS: *Zagreb je grad. Hrvatska je zemlja. More je veliko — ne, samo: More!* (keep adjective out — agreement comes in L3): **Zagreb je grad. Kanada je zemlja. To je selo.** → MC ×3: pick the gender (jezik? kava? selo?) → Teach: trap nouns (tata, večer, noć) + U1 words re-sorted (dan m, večer f!, jutro n) → match: 5 known U1 words ↔ gender labels (pairs must stay unambiguous — one label per word; broader gender sorting continues in the flashback quiz) → type ×2: "To je zemlja", "Kanada je zemlja" → fill ×2 with word bank → listen-type ×2 (*To je selo.* · *Kanada je zemlja.*) → speak: say one gender triple aloud (*grad — zemlja — selo*) → interleave ×2 → Recap
- **Interleaving:** U1 items as gender-sorting material: kava, čovjek, škola, ime, večer (also recycles Dobra večer! from U1 L5)
- **SRS:** L1 vocab (recognition + production); gender-tag cloze cards ("noć = __ gender"); chunk card "Ja sam iz Kanade / iz Hrvatske" **(chunk, not yet analyzed — GEN in Unit 7)**

### L2 — Nisam! Jesi li? (biti negation + yes/no questions)

- **Grammar micro-point:** negative biti (nisam/nisi/nije/nismo/niste/nisu — fused, one word); yes/no questions with verb + li (Jesi li…? Je li…?); short answers Jesam./Nisam. → grammar-reference §6, §15
- **New vocab:** L2 set
- **Required visuals:** biti three-column table (clitic sam · stressed jesam · negative nisam), endings color-bolded; question-formation before→after transformation with moving-word highlight (Ti **si** student. → **Jesi li** student?)
- **Slide arc:** Hook: "Say no, ask anything: two superpowers in one lesson." → Teach: nisam column next to the U1 sam column → Examples + TTS: **Nisam Hrvat, Kanađanin sam. Marko nije iz Zagreba, on je iz Splita. Jesi li ti studentica? — Jesam!** → MC ×3 (pick the right negative form: Mi ___ iz Njemačke) → Teach: verb + li question rule + transformation visual; short answers Jesam/Nisam (stressed forms CAN stand first — unlike sam!) → fill ×3: build questions (___ li ti Englez?) → type ×2: translate "I am not a teacher", "Is she from Croatia?" (Nisam učitelj / učiteljica; Je li ona iz Hrvatske?) → reorder: li / iz / jesi / Kanade → listen-type ×2 (Nisam iz Amerike.) → speak: answer "Jesi li ti Hrvat/Hrvatica?" truthfully → interleave ×2 → Recap
- **Interleaving:** U1: Kako si? (contrast with Jesi li…), biti affirmative fill (Ona ___ studentica), gospodin/gospođa
- **SRS:** L2 vocab; cloze cards all 6 nisam forms; question↔answer chunk cards (Jesi li…? ↔ Jesam./Nisam.); chunk "Odakle si? — Iz Kanade." **(iz + name = chunk, not yet analyzed)**

### L3 — Dobar, dobra, dobro (Adjective agreement NOM sg)

- **Grammar micro-point:** adjectives copy the noun's gender: -∅ (m) / -a (f) / -o (n); fleeting a in m forms (dobar→dobra, sretan→sretna). You already know this: **dobar dan, dobra večer, dobro jutro!** → grammar-reference §4 (NOM row only)
- **New vocab:** L3 set
- **Required visuals:** agreement mini-table (3 genders × endings, endings bolded in gender colors); fleeting-a warning card (dob**a**r → dobra, never ~~dobara~~); profession pairs grid (m/f columns with icons)
- **Slide arc:** Hook: "You've been doing agreement since day 1: dobar dan, dobra večer, dobro jutro." → Teach: -∅/-a/-o rule + table → Examples + TTS: **Čaj je dobar. Kava je dobra. Jutro je dobro.** + *Tom je dobar student. Ana je dobra studentica.* → MC ×3 (Ona je ___ učiteljica: dobar/dobra/dobro) → Teach: professions come in m/f pairs (konobar/konobarica…) + fleeting a → match: profession m ↔ f forms → fill ×3: adjective endings (Marko je ___ konobar. (dobar)) → type ×2: "Ana je nova liječnica", "On je loš kuhar" → listen-type ×2 (*Kava je dobra.* · *On je dobar kuhar.*) → speak: describe yourself with two adjectives (Ja sam… i…) → interleave ×3 → Recap
- **Interleaving:** U1: sretan/umoran now inflected (Ana je sretna, umorna — new forms of known words), loše (U1 adverb → adjective loš), odlično
- **SRS:** L3 vocab; cloze cards for -∅/-a/-o endings on dobar/nov/loš; profession-pair cards (učitelj↔učiteljica)

### L4 — Brojevi 1–20 (Numbers)

- **Grammar micro-point:** numbers 1–20 as counting words only; the 11–19 -naest pattern; jedan/jedna/jedno agrees like an adjective (preview — noun government with 2–4 and 5+ deferred to Unit 7). → grammar-reference §13
- **New vocab:** L4 set
- **Required visuals:** number grid 1–20 with the -naest pattern highlighted (jedan**aest**, dvan**aest**…); jedan/jedna/jedno agreement mini-card (gender colors); ⚠️ deferral note card "counting only — nouns after numbers come in Unit 7" (bracket diagram itself deferred to U7)
- **Slide arc:** Hook: "Count to 20 and you can handle prices, ages, and phone numbers." → Teach: 1–10 + TTS per number → listen-type ×3 (TTS says *sedam*, *devet*, *četiri* — learner types) → Teach: 11–20, the -naest pattern → MC ×3 (hear TTS, pick the digit) → fill ×2: arithmetic (Koliko je dva i tri? — **Pet.** · Deset i deset je **dvadeset**.) → type ×2: spell out 14, 19 (četrnaest, devetnaest) → reorder: je / koliko / to → speak: count 1–10 aloud; read a phone number digit by digit → interleave ×2 → Recap
- **Interleaving:** U1: da/ne (Je li to pet? — Ne!), molim (Broj, molim!); U2 L2: Je li…? question frame around numbers
- **SRS:** all 20 numbers (recognition + production + listening priority — numbers are an ear skill); cloze "11–19 end in ___ (-naest)"; cloze "Koliko je pet i pet? → deset"

### L5 — Govorim hrvatski (govoriti + languages, unit review)

- **Grammar micro-point:** govoriti fully conjugated (govorim/govoriš/govori/govorimo/govorite/govore) — first full verb, presented as a preview of the -im class (formal class treatment in Unit 4); language names after govoriti (govorim hrvatski — looks like the dictionary form, no visible change; flagged as pattern-not-yet-analyzed). → grammar-reference §7
- **New vocab:** L5 set
- **Required visuals:** govoriti conjugation table (6 persons, endings bolded and colored); country → nationality → language mapping grid (Hrvatska → Hrvat/Hrvatica → hrvatski) with flags
- **Slide arc:** Hook: "By the end of this lesson you can say the most useful sentence a learner owns: Govorim malo hrvatski." → Teach: govoriti table (endings mirror biti rhythm: -m -š -∅ -mo -te) → Examples + TTS: **Govorim hrvatski i engleski. Govoriš li njemački? — Ne, ali govorim francuski. Ne razumijem. Molim?** → MC ×3 (Oni ___ engleski: govore/govorimo/govoriš) → Teach: country→nationality→language grid + razumijem/ne razumijem survival chunk → fill ×3 (Ana je Hrvatica i govori ___.) → type ×2: "We speak English", "I speak a little Croatian" (Govorimo engleski; Govorim malo hrvatski) → listen-type ×2 → speak: say which languages you speak → integration ×2: story-cast items (Je li Marko konobar? Odakle je Tom?) → Recap + unit-review slide set (8 quiz slides sampling L1–L4)
- **Interleaving:** U1: oprostite + ne razumijem as a politeness combo, Kako se zoveš? in the L5 dialogue; U2 L4: numbers ×1 (listen-type)
- **SRS:** L5 vocab; cloze cards all 6 govoriti forms; mapping cards (Njemačka → Nijemac → njemački)

## Story — «Odakle je Tom?» (Where is Tom from?)

In the café, Ana asks Tom where he is from. Tom is a Canadian from Toronto: he speaks English and a little Croatian, and he is not a tourist — he is a student. Marko brings coffee and adds that he is not from Zagreb: he is from Split. Ana teaches Tom to count to ten, and Tom counts — slowly, but happily. 80–120 words, present tense, NOM + flagged iz-chunks only.
Cast: Tom, Ana, Marko. New glossed words (≤5): turist (tourist), daleko (far), sada (now), polako (slowly).
Sample sentences: »Odakle si, Tom?« — »Ja sam iz Kanade. A ti?« — »Ja sam Hrvatica, iz Zagreba.« · »Marko nije iz Zagreba — on je iz Splita.« — »Molim, polako! Ne razumijem.«
Comprehension: 5 MC questions (Odakle je Tom? Je li Tom turist? Odakle je Marko? Što Tom govori? Kako je Tom sada?).

## Unit test blueprint (16–18 items, pass ≥ 70%)

1. **Vocab (5):** match HR↔EN professions ×2, MC nationality→country ×2, MC number word → digit ×1
2. **Grammar (6):** nisam-family fill ×2 (Mi ___ iz Engleske. — nismo), Jesi li question build (reorder) ×1, adjective agreement fill ×2 (Kava je ___. — dobra), govoriti form fill ×1 (Oni ___ hrvatski. — govore)
3. **Listening (4):** listen-type numbers ×2 (TTS: petnaest, osam), listen + MC meaning ×2 (Nisam Nijemac, Englez sam.)
4. **Reading (3):** 4-line mini-dialogue (Odakle si? …) + 3 MC comprehension
Example item: fill — »___ li ti liječnica?« (Jesi) · type — translate "She is a good teacher" (Ona je dobra učiteljica).

## NotesDoc focus per lesson

- **L1:** full gender table incl. all traps (tata, kolega m; noć, večer, stvar, ljubav f; ime n); mistakes: guessing gender from English meaning, treating -a masc nouns as feminine (tata je dobra ❌ → dobar ✅); hook: "the word's END tells you, not its meaning"; flag iz-chunks explicitly (iz Kanade — memorize whole, dissect in Unit 7)
- **L2:** complete three-column biti table (clitic/stressed/negative); mistakes: ~~ne sam~~ ❌ → nisam ✅ (fused!), ~~Je li ti…~~ ❌ → Jesi li ti ✅ (verb agrees with subject), answering Jesi li with da/ne alone instead of Jesam/Nisam (both fine, teach the native-like short answer); note Da li… as heard-but-not-taught
- **L3:** full NOM-row agreement table + fleeting-a list (dobar, sretan, umoran); mistakes: default masculine everywhere (Ana je dobar ❌ → dobra ✅), ~~dobra jutro~~ ❌ → dobro jutro ✅; hook: the greetings you already know ARE the paradigm
- **L4:** number grid + spelling traps: četiri (not ~~četri~~), the -naest chant; mistake: pronouncing numbers with English stress (stress never final); note: NO nouns after 2+ yet — that trap is defused in Unit 7
- **L5:** full govoriti table; mistakes: ~~govorim hrvatskom~~ ❌ → govorim hrvatski ✅, ~~Ja govorim, ti govoriš…~~ pronoun overuse (pro-drop recycled from U1), razumijem vs razumiješ mix-ups; hook: -m -š -∅ -mo -te endings will repeat for EVERY verb class
