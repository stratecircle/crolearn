# A1 Unit 1 — Dobar dan! (Greetings & Introductions)

> **EXEMPLAR UNIT SPEC.** All other unit specs follow this structure (template: [../01-teaching-method.md](../01-teaching-method.md) §11).

## Overview

The entry point of the whole course. Two lessons buy the single biggest early win in Croatian — the fully phonetic alphabet ("read exactly as written") — so that from Lesson 3 onward the learner can pronounce ANY word they see. Then `biti`, pronouns, and question phrases give the first real conversations. No cases yet: everything stays in nominative as unanalyzed wholes.

## Can-do objectives

- I can pronounce any written Croatian word aloud (and spell what I hear)
- I can greet people correctly by time of day, formally and informally
- I can introduce myself and ask someone's name
- I can say how I am and ask how someone is
- I can use da/ne/hvala/molim politely

## New vocabulary (~40 items)

**L1 (phonetics carriers + first words):** da (yes) · ne (no) · i (and) · dobro (good/well) · jutro (n, morning) · dan (m, day) · večer (f, evening) · noć (f, night) · kava (f, coffee) · voda (f, water)

**L2 (phonetics carriers):** čaj (m, tea) · čovjek (m, person/man) · đak (m, pupil) · džep (m, pocket) · ljeto (n, summer) · njegov (his) · škola (f, school) · žena (f, woman/wife) · ćao (hi/bye, colloq.) · Hrvatska (f, Croatia)

**L3:** ja · ti · on · ona · ono · mi · vi · oni/one · tu (here) · sretan (happy) · umoran (tired) · student (m) / studentica (f)

**L4:** kako (how) · tko (who) · što (what) · ime (n, name) · prijatelj (m, friend) / prijateljica (f) · gospodin (m, Mr./sir) · gospođa (f, Mrs./madam) · drago mi je (nice to meet you) · zovem se (my name is) · a ti? / a Vi? (and you?)

**L5:** hvala (thank you) · molim (please/you're welcome) · oprosti/oprostite (sorry/excuse me) · izvoli/izvolite (here you go) · doviđenja (goodbye) · bok (hi/bye) · laku noć (good night) · vidimo se (see you) · dobrodošli (welcome) · odlično (excellent) · loše (bad/poorly) · može (OK, sure)

## Lessons

### L1 — Slova i glasovi I (The alphabet: read as written)

- **Grammar micro-point:** Croatian orthography is 1 letter = 1 sound; the 5 pure vowels; stress never final. → grammar-reference §1
- **New vocab:** L1 set above
- **Required visuals:** full 30-letter alphabet grid (familiar letters dimmed, new ones highlighted); vowel mouth-shape diagram; side-by-side "English guess vs Croatian reality" table (e.g. *je* ≠ "jee")
- **Slide arc:** Hook: "In 2 lessons you'll pronounce EVERY Croatian word — Croatian is 100% phonetic." → Teach: alphabet grid + vowels (a e i o u always pure) → Examples with TTS: dan, dobro, voda, kava, jutro + first phrases: *Dobro jutro!* · *Da, kava i voda.* → MC ×4: "which sound does *j* make?" type → Teach: r can be a vowel (prst, Hrvatska) → match ×1: letter ↔ sound (j, c, i, e vs their English look-alikes) → listen-type ×4: TTS plays *voda* → learner types it → type ×2: production from EN prompt ("coffee" → kava · "good morning" → dobro jutro) → speak ×2: dan, dobro jutro → Recap
- **Interleaving:** none (first lesson)
- **SRS:** L1 vocab (recognition+production); cloze card "j = __ sound"

### L2 — Slova i glasovi II (č ć dž đ lj nj š ž)

- **Grammar micro-point:** the 8 "new" letters + digraphs lj/nj/dž are single sounds. → grammar-reference §1
- **New vocab:** L2 set
- **Required visuals:** hard/soft pair diagram (č↔ć, dž↔đ on a hardness slider); minimal-pair table with TTS (čaj/ćao); keyboard hint card (on-screen č ć đ š ž buttons)
- **Slide arc:** Hook: "8 new letters and you're done — forever." → Teach: š ž (easy: sh, zh) → listen-type ×2 (škola, žena) → Teach: č vs ć, dž vs đ (learner tip: many natives barely distinguish — don't stress) → MC minimal pairs ×3 (hear TTS, pick spelling) → Teach: lj nj as one sound → listen-type ×4 (ljeto, čovjek, Hrvatska, džep) → speak ×2 (čaj, ljeto) → interleave: type *voda*, *jutro* from L1 → Recap: "you can now read ANYTHING — prove it": reorder slide building *Dobar dan, Hrvatska!*
- **Interleaving:** L1 vocab ×2
- **SRS:** L2 vocab; listening cards enabled early for this unit (phonetics is the point)

### L3 — Ja sam… (biti + pronouns)

- **Grammar micro-point:** present of `biti` (clitic forms sam/si/je/smo/ste/su); personal pronouns; **pro-drop** (Ja sam Ana → Sam Ana ❌ / Ana sam ✅ — clitic can't be first!). → grammar-reference §5, §6
- **New vocab:** L3 set
- **Required visuals:** biti conjugation table (6 persons, endings color-bolded); pronoun grid with icons (👤 ja, 👥 mi…); ⚠️ word-order card: "sam/si/je never stands first"
- **Slide arc:** Hook: "Say who you are, in 3 words." → Teach: biti table → Examples + TTS: Ja sam Tom. Ti si student. Ona je Ana. Mi smo prijatelji. → MC ×3 (pick the right form: Ona ___ studentica) → Teach: pro-drop + second-position rule (Umoran sam. / Ja sam umoran. both ✅; Sam umoran ❌) → fill ×3 (word bank) → type ×2: translate "I am Tom", "We are friends" → match: pronouns ↔ biti forms → listen-type ×2 (*Ona je studentica.* · *Mi smo prijatelji.*) → speak: Ja sam [ime]. Drago mi je. → interleave ×2 from L1/L2 (type *voda* from EN prompt; listen-type *čovjek*) → Recap
- **SRS:** pronouns + vocab; cloze cards for all 6 biti forms
- **Common-mistake note (for NotesDoc):** clitic-first (*Sam Ana*), overusing pronouns (*Ja sam, ti si* everywhere = unnatural)

### L4 — Kako se zoveš? (First questions)

- **Grammar micro-point:** question phrases as fixed chunks: Kako se zoveš?/Kako se zovete? · Tko je to? · Što je to? · Kako si?/Kako ste? (zvati se conjugation deferred to Unit 6 reflexives — here it's a chunk). → grammar-reference §15
- **New vocab:** L4 set
- **Required visuals:** question-word cards with icons (tko 👤, što ⬛, kako ❓); mini-dialogue flow diagram (greeting → name → drago mi je → response)
- **Slide arc:** Hook: a full first-meeting dialogue played via TTS — "by the end of this lesson this is you." → Teach: Kako se zoveš? → Zovem se… / Ja sam… → Examples + TTS ×4 → type ×2 → Teach: Tko/Što je to? → To je… (To je Ana. To je kava.) → MC ×3 → fill: dialogue with blanks → reorder ×2: se / zoveš / kako → listen-type ×2: *Zovem se Marko.* · *Drago mi je.* → speak: answer "Kako se zoveš?" out loud → interleave ×3 (L1: greeting-by-time MC; L2: listen-type *čovjek*; L3: fill *Ona ___ studentica*) → Recap
- **SRS:** vocab + chunk cards (question↔answer pairs as cloze)

### L5 — Molim i hvala (Courtesy, ti vs Vi, unit review)

- **Grammar micro-point:** courtesy system + **ti/Vi register preview** (Kako si? vs Kako ste? — full treatment at B2 U30, here just "friends vs strangers/elders"). No new grammar machinery.
- **New vocab:** L5 set
- **Required visuals:** ti/Vi decision mini-flowchart (friend/child → ti; stranger/older/service → Vi); time-of-day greetings arc diagram (jutro ☀️ dobro jutro → dan 🌤️ dobar dan → večer 🌆 dobra večer → noć 🌙 laku noć)
- **Slide arc:** Hook: "Politeness is half the language." → Teach: greetings by time of day + arc diagram → match: time icon ↔ greeting → Teach: hvala/molim/izvolite/oprostite micro-dialogues (café: Kavu, molim. — Izvolite. — Hvala.) → MC ×3 → Teach: ti vs Vi flowchart → MC ×3 (situation → ti or Vi?) → integration: build the full unit dialogue (reorder + fill, story cast: Tom meets Ana) → listen-type ×2 → speak: full self-introduction (greeting + name + drago mi je) → Recap + unit-review slide set (8 quiz slides sampling L1–L4)
- **SRS:** vocab; dialogue-chunk cloze cards

## Story — «Tom u Zagrebu» (Tom in Zagreb)

Tom, a Canadian learning Croatian, lands in Zagreb and meets Ana (studentica) in a café; Marko (konobar) serves them. Pure Unit-1 language: greetings, introductions, biti, courtesy chunks. 60–90 words, present tense, nominative only.
Cast: Tom, Ana, Marko. New glossed words (≤5): zračna luka (airport), grad (city), naravno (of course), super (great).
Sample sentences: »Dobar dan! Ja sam Tom.« — »Drago mi je! Ja sam Ana, a ovo je Marko.« · »Kavu, molim.« — »Izvolite!« — »Hvala!«
Comprehension: 4 MC questions (Tko je Ana? Što Tom pije? …).

## Unit test blueprint (15–18 items, pass ≥ 70%)

1. **Vocab (5):** match HR↔EN ×2, MC ×3
2. **Grammar (5):** biti forms fill ×3, word-order reorder ×1 (clitic not first), ti/Vi situation MC ×1
3. **Listening (4):** listen-type ×2 (dictation), listen + MC meaning ×2
4. **Reading (3):** 3-line mini-dialogue + 3 MC comprehension
Example item: fill — »Dobra ___! Kako ste?« (večer) · listen-type — TTS says *čovjek*, learner types it.

## NotesDoc focus per lesson

- **L1/L2:** full pronunciation chart as a table; mistakes: reading *je* as "jee", English diphthong vowels, ignoring diacritics ("č is not c"); hook: "diacritics are letters, not decoration"
- **L3:** complete biti table (incl. stressed jesam and negative nisam as a preview of U2); mistakes: clitic-first, pronoun overuse; hook: "sam-si-je-smo-ste-su" chant rhythm
- **L4:** dialogue map diagram; chunks-not-grammar framing; mistake: translating word-by-word ("How yourself call you?")
- **L5:** ti/Vi flowchart reproduced; greeting-arc diagram; mistakes: dobar večer ❌ → dobra večer ✅ (večer is feminine!), bok with strangers
