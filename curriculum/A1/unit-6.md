# A1 Unit 6 — Moj dan (Daily Routine & Time)

## Overview

The learner can now locate things (U5) and want things (U4); this unit adds TIME — clocks, days, and daily routines. The big payoff: **zvati se from Unit 1 finally gets analyzed** when reflexive verbs are taught, and the second-position clitic rule (known from `sam/si/je`) extends naturally to `se`. ACC plural completes the accusative picture started in U4. No new cases.

## Can-do objectives

- I can describe my daily routine from waking up to going to bed
- I can tell the time and say at what time I do things
- I can name the days of the week and say what I do on which day
- I can say how often I do something (always/often/sometimes/never)
- I can talk about doing/liking multiple things (ACC plural)

## New vocabulary (~40 items)

**L1 (reflexive routine):** buditi se (wake up) · ustajati (get up) · tuširati se (shower) · oblačiti se (get dressed) · odmarati se (rest) · ići spavati (go to bed, chunk) · spavati (sleep) · rano (early) · kasno (late) · zatim (then)

**L2 (time):** sat (m, hour/clock) · minuta (f, minute) · pola (half) · podne (n, noon) · ponoć (f, midnight) · vrijeme (n, time/weather) · ujutro · prijepodne · popodne · navečer

**L3 (ACC-plural carriers):** film (m) · knjiga (f) · pjesma (f, song) · zadaća (f, homework) · vijesti (f pl, news) · jezik (m, language) · sport (m) · serija (f, series) · slušati (listen) · učiti (study/learn)

**L4 (days & frequency):** ponedjeljak (m) · utorak (m) · srijeda (f) · četvrtak (m) · petak (m) · subota (f) · nedjelja (f) · uvijek · često · ponekad · rijetko · nikad(a) · svaki dan (chunk) · tjedan (m, week)

**L5 (routine glue):** doručkovati (have breakfast) · ručati (have lunch) · večerati (have dinner) · počinjati (begin) · završavati (finish) · obično (usually)

## Lessons

### L1 — Budim se rano (Reflexive verbs)

- **Grammar micro-point:** reflexive verbs = verb + clitic `se`; `se` obeys the same second-position rule as sam/si/je. **Payoff: Kako se zoveš? / Zovem se… (U1 chunk) is now fully analyzed.** → grammar-reference §7, §12
- **New vocab:** L1 set
- **Required visuals:** routine icon strip (⏰ budim se → 🚿 tuširam se → 👕 oblačim se → ☕ doručkujem); ⚠️ second-position card extended: "se is a clitic like sam — never first" ; conjugation table buditi se (budim se, budiš se…)
- **Slide arc:** Hook: "Zovem se — you've said it since day one. Today you'll know WHY it works." → Teach: se as reflexive clitic + buditi se table → Examples + TTS: Budim se u sedam. Tuširam se navečer. Ana se budi rano. (se placement contrast!) → MC ×3 (pick correct se position: Ana **se** budi / ~~Se budim~~ ❌) → Teach: routine verbs with icon strip → fill ×3 (word bank) → reorder ×2: se / rano / budim → type: "I get dressed" → listen-type ×2 (*Ana se budi rano.* · *Tuširam se navečer.*) → speak: Budim se u sedam. → interleave: U5 Idem na posao, U4 Pijem kavu → Recap
- **Interleaving:** U5 (idem u/na), U4 (pijem, jedem), U1 (zovem se — now re-filed as grammar)
- **SRS:** L1 vocab; cloze cards for se-placement (Ana ___ budi rano → se)
- **Watch-out (NotesDoc):** ~~Budim rano~~ ❌ (dropping se); ~~Se tuširam~~ ❌ (se first)
- *Authoring deviation (a1u6l1): the icon strip drops »doručkujem« (the breakfast verb doručkovati is carded in L5) and closes the day with L1-only vocab (odmaram se → idem spavati); »Tuširam se navečer« → »Tuširam se kasno« (navečer is L2 vocab). Clock times (»u sedam«) appear only as a glossed preview in teach examples — no L1 quiz depends on them.*

### L2 — Koliko je sati? (Telling time)

- **Grammar micro-point:** Koliko je sati? · full hours (Sedam je sati — sati = GEN-pl pattern from U7? NO — taught as a **fixed chunk**, analyzed next unit) · half hours: **pola osam = 7:30** (half TO eight, not half past seven!) · "at": u + time (u sedam, u pola devet). → grammar-reference §13 (numbers)
- **New vocab:** L2 set
- **Required visuals:** clock-face diagram pair with the **pola trap** flagged big (🕢 = pola osam, arrow to the NEXT hour); day-arc timeline (ujutro → prijepodne → podne → popodne → navečer → noć → ponoć) reusing U1's greetings arc
- **Slide arc:** Hook: TTS voice asks Koliko je sati? over a clock face → Teach: full hours (Jedan je sat. Dva/tri/četiri su sata. Pet je sati. — presented as chunks-by-number) → listen-type ×2 (TTS time → type digits) → Teach: the pola rule with clock diagram → MC ×4 (clock face → pick pola osam vs pola sedam — the classic trap) → Teach: u + time for "at" (Budim se u sedam. Ručam u pola jedan.) → fill ×2 → type ×2: "I shower at eight" (Tuširam se u osam.) · "I have lunch at half past twelve" (Ručam u pola jedan.) → speak: say at what time you wake up (*Budim se u sedam.*) → interleave ×2 → Recap
- **Interleaving:** L1 reflexives with times; U2 numbers 1–20 (heavy recycle)
- **SRS:** time chunks as cloze; listening cards prioritized (times are an ear skill)
- **Watch-out:** pola osam ≠ 8:30 (the #1 trap of this unit — drill it)
- *Authoring deviation (a1u6l2): the two dictation slides take the spoken Croatian time sentence (the app's listen-type is "type what you hear"); the hear→digits skill is drilled as a TTS multiple-choice battery instead.*

### L3 — Volim filmove (ACC plural)

- **Grammar micro-point:** ACC plural: masc **-e** (filmovi→filmove), fem **-e** (= NOM pl), neut **-a** (= NOM pl). Only masculine visibly changes; no animate/inanimate split in plural. → grammar-reference §3
- **New vocab:** L3 set
- **Required visuals:** ACC-red declension table sg+pl side by side (completing the U4 table); "only masc changes" spotlight diagram (filmovi→film**ove**, knjige→knjige, sela→sela)
- **Slide arc:** Hook: "You can already say Volim film. Today: Volim filmove — all of them." → Teach: ACC pl table → Examples + TTS: Gledam filmove. Slušam pjesme. Učim jezike. Ana voli serije. → MC ×3 (pick the form: Volim ___ — knjige/knjiga) → fill ×3 → type ×2: "I watch series", "We listen to songs" → match: NOM pl ↔ ACC pl pairs → listen-type ×2 (*Slušam pjesme.* · *Gledamo filmove.*) → interleave ×3 (U4 ACC sg items: Pijem kavu; U3 NOM plurals) → speak: Navečer gledam vijesti. → Recap
- **Interleaving:** U4 ACC sg (contrast), U3 NOM plural (contrast)
- **SRS:** vocab; cloze grammar cards (Gledam ___ (film, pl) → filmove)
- *Authoring deviation (a1u6l3): »jezik« stays a REVIEW word (taught in Unit 2) — used to show ACC pl »jezike« but not re-carded as new U6 vocab (L3 set = 9 items). The match drills EN↔ACC-pl forms rather than NOM-pl↔ACC-pl pairs, since fem/neut pairs would be identical.*

### L4 — Svaki dan (Days & frequency)

- **Grammar micro-point:** days of the week (no capitals!); "on Monday" = **u + ACC** (u ponedjeljak, u srijedu — ACC payoff!); frequency adverbs and their default pre-verb slot; **nikad + ne = mandatory double negative** (Nikad ne učim navečer). → grammar-reference §14 (u + ACC)
- **New vocab:** L4 set
- **Required visuals:** week-strip calendar (pon–ned) with u-phrases under each day, fem days (srijeda→u srijedu, subota→u subotu) color-flagged ACC-red; frequency thermometer diagram (uvijek 🔥 → nikad ❄️); ⚠️ double-negative card
- **Slide arc:** Hook: "Say what your week looks like." → Teach: days + u + ACC (u petak, u subotu) → match: day ↔ u-phrase → Teach: frequency thermometer + word order (Često gledam filmove. / Ne učim nikad ❌ → Nikad ne učim ✅) → MC ×3 → fill ×3 (calendar-based: U srijedu ___ hrvatski — učim) → reorder: ne / nikad / kavu / pijem / navečer → listen-type ×2 → interleave ×3 → speak: U subotu se odmaram. → Recap
- **Interleaving:** L1–L3 of this unit; U2 numbers; U4: Pijem kavu (frequency adverb + ACC: *Često pijem kavu.*); U5: Idem na posao (u + day: *U ponedjeljak idem na posao.*)
- **SRS:** days (7 cards + u-form cloze); frequency adverbs
- **Watch-out:** days lowercase; ~~u srijeda~~ ❌ → u srijedu ✅; single-negative English habit (*Nikad učim* ❌)
- *Authoring deviation (a1u6l4): the spec marks »Ne učim nikad« ❌, but that word order is in fact grammatical; the lesson teaches the target »Nikad ne učim« and frames the REAL error as dropping ne (»Nikad učim« ❌). vocabPolicy: closed-set (14 items: 7 days + 5 frequency adverbs + svaki dan + tjedan).*

### L5 — Moj tipičan dan (My typical day — integration & review)

- **Grammar micro-point:** none new — full-day narration combining reflexives + times + days + frequency + ACC sg/pl. Sequencers: prvo, zatim, onda, na kraju.
- **New vocab:** L5 set
- **Required visuals:** full-day timeline template (the learner's own day gets slotted in); sequencer arrow chain (prvo → zatim → onda → na kraju)
- **Slide arc:** Hook: TTS plays Ana's full day monologue (6 sentences) — "yours by the end." → Teach: meal verbs + sequencers → Examples + TTS: *Prvo se budim, zatim doručkujem.* · *Obično večeram u sedam.* → fill: Ana's day with blanks → reorder ×2 (full sentences) → listen-type ×2: *Doručkujem u pola osam.* · *Večeram u sedam navečer.* → integration: build Tom's day (7-slide guided chain, each adds one sentence) → speak ×2: two sentences of YOUR day → unit-review set: 8 quiz slides sampling L1–L4 (incl. one pola clock, one se-placement, one nikad ne) → Recap
- **Interleaving:** whole unit + U4 café (doručak: Pijem kavu i jedem kruh); U5: Idem na posao u osam (direction + time)
- **SRS:** meal verbs, sequencers; the learner's own day sentences become custom cards

## Story — «Tipičan dan» (A typical day)

Tom narrates his Zagreb routine: waking early, showering, coffee at Marko's café, Croatian class (Učim hrvatski svaki dan!), evening series with Ana. Baka Marija calls (Ona se budi u pet ujutro! — village contrast for humor). 100–150 words, present tense, heavy reflexives/times/days.
Cast: Tom, Ana, Marko, baka Marija. Glossed (≤5): selo (village — promoted from passive), rano ujutro (early morning, chunk), zauzet (busy), život (life).
Sample sentences: »Budim se u sedam i tuširam se.« · »U subotu se Tom i Ana odmaraju i gledaju serije.«
Comprehension: 4 MC (Kada se Tom budi? Što Tom radi navečer? …)
*Authoring deviation (a1u6story): names stay in the nominative in address (»Bok, Tom!«) — the vocative is deferred to A2 U14; »s Anom« (INS, A2 U12) is replaced by »Ana i ja gledamo…«. Glossed (3, all genuinely new or chunk): rano ujutro, zauzeta, život. selo/rano/ujutro are already taught, so used unglossed. 5 comprehension MC (blueprint said 4 — added one).*

## Unit test blueprint (16–18 items, pass ≥ 70%)

2. **Grammar (6):** se-placement reorder ×2, ACC pl fill ×2, u + day fill ×1, double-negative MC ×1
3. **Listening (4):** time dictation ×2 (incl. one pola trap), listen + MC ×2
4. **Reading (3):** 4-line routine text + 3 MC
